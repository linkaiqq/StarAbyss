## 1. 现状分析

| 项目 | 实际情况 |
| --- | --- |
| 引擎 | Godot **4.7.2.stable.official**（`ed1daf0bf`），Forward+ / Vulkan 1.4.325 |
| 语言 | 纯 GDScript，**无 C#、无插件、无第三方依赖** |
| 脚本 | 40 个 `.gd`（`godot/scripts/`） |
| 场景 | 16 个 `.tscn`（`godot/scenes/`） |
| 数据资源 | 20 个 `.tres`：攻击、祝福、房间、敌人、Boss 招式、导航网格 |
| 音频 | 27 个 `.wav`；模型 7 个 `.glb` |

这意味着数值策划改数值**不需要改代码**，只需改资源 + 改测试期望值。

### 1.2 玩法与内容现状（已核实）

```
主菜单 → 遗迹前庭(2 哨兵) → 祝福三选一 → 星辉回廊(3 哨兵) → 祝福三选一 → 晶核封印(Boss) → 胜利/失败 → 重开/返回菜单
```

- **操作**：WASD 移动、跳跃、左键三连击（12/16/24）、右键/E 星刃斩（35 伤害，5 m、70° 扇形，8 s CD）、Shift 闪避（0.45 s，无敌帧 [0.10, 0.30) s，CD 1.2 s）
- **玩家**：HP 100，重力 18 m/s²
- **敌人**：哨兵 45 HP / 3.2 m/s / 攻击 CD 1.3 s（2 种以上编队：2 只、3 只）
- **Boss**：晶核守卫 350 HP / 2.6 m/s / 招式间隔 1.6–2.4 s；横扫 0.8 s 前摇、360° 冲击 1.2 s 前摇
- **祝福**：仅 **3 种** —— 烈焰之刃（普攻 ×1.20）、生命共鸣（+20 HP，击杀回 5）、疾风步伐（闪避 CD → 0.9 s）
- **局内 HUD（已核实存在）**：房间进度 `02 / 03`、目标行、剩余敌人计数、用时/击杀/种子、已获祝福列表、HP、技能冷却、闪避冷却、Boss 血条 + **Boss 当前招式预警**
- **叙事**：弹窗有副标题式文本（如"抵达晶核封印 —— 打通外层回廊，直面晶核守卫"），但**没有对话系统、没有角色、没有世界观呈现**

### 1.5 必须如实记录的已知限制（v1.0.0 遗留）

1. **图形测试对桌面焦点敏感**：`run_manager.gd:58` 在窗口失焦时自动暂停（**这是正确的玩家行为**，alt-tab 必须暂停）。若测试期间有其他窗口抢焦点，战斗循环会立刻退出，表现为"玩家满血、敌人未清"的假失败；鼠标捕获检查同样依赖焦点。
   - 已做加固：战斗循环检测到 `PAUSED` 自动 `resume()` 并计数；结果行新增 `focus pauses: N`；鼠标捕获改为最多等待 300 帧，仍失败则输出 `ABORT: desktop focus unavailable …` 明确标注为环境无效而非游戏缺陷；预置条件缺失时 fail-fast，不再让协程中断导致整套件挂起。
   - 实测：加固后连续 3 次全量套件中 2 次 21/21 全绿，1 次因 5 秒内窗口始终未获得焦点而 `room-integration` 中止（**同一轮 headless 501 断言 0 失败**）。
   - 结论：**这是测试环境的限制，不是游戏缺陷**；但也不得宣称套件"100% 确定性通过"。
2. `user://` 在本机不可写（Vulkan 着色器缓存无法落盘），游戏优雅降级仅告警 —— 性能数据因此为最坏情况冷启动。
3. 无人工视觉评审：所有美术声称基于像素统计，`human_playtest_verified` 保持 `false`。
4. 无难度选项、无元进度（解锁/货币/存档）、无设置菜单（仅音量开关）。
5. 文案为代码内硬编码中文；资源上的 `localization_key` 未被实际用于文本渲染。

| 全流程无法致死、阵亡率 0% | 按实测利用率重算，Boss 房阵亡率 11.0%；且 DP 独立推导得 11.12%，两模型互证 | `DESIGN_REVIEW §8`、`DIFFICULTY_DESIGN §3.6` |

### 四、当前核心设计结论

1. **防御主力是「打断 + 后撤」，不是「闪避帧」**：打断率房 1 为 50.7%、房 2 为 39.4%，是最大单一减伤来源；Boss `stagger_duration = 0.0` 不可打断，靠读预警后撤（夹具 `_boss_input()` 即此策略，35 s Boss 战零掉血）。
2. **疾风步伐价值≈0**：受击保护 0.5 s 与闪避 CD 1.2 s 在 1.53 s 出手节奏下**从不成为约束**。
3. **第 2 房缺少难度台阶是事实，但本期不应加压**：贪刀机器人两房合计仅掉 10 HP，但这反映的是**逐帧完美操作**而非真人难度——D2 模拟的新手档整局阵亡率已达 **35.0%**。在无检查点、死亡即整局重来（5–8 分钟）的前提下继续加压会恶化体验，故 M1 **撤销不实施**，完整方案留作下一版。
4. **保留设计不变量 `_max_actions <= 1`**（`room_integration_test.gd:115`，全库唯一限制多敌并发之处）。为 29 小时窗口内的一档难度微调而改写其适用范围，收益/风险比不成立。
