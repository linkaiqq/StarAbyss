## 1. 世界观总述

### 1.1 时代背景

遗迹是**已亡文明的守夜建筑**。这里曾有一座以星辉为能源的城（文献层称「星庭」，**游戏内不出现**该词，仅作设定支撑）。星庭不是被战争毁灭的，而是被自己的能源反噬：他们熄灭时，把最后一件事托付给了建筑 —— 守住星渊。

遗迹里没有活人。**留下的只有"仍在执勤"的造物**：门、巡守、守卫。它们不腐化、不疯狂、不憎恨，只是继续执行一条已经没有人能撤销的旧令。这就是本作的敌人来源，也是本作"无 NPC"的设定级理由：**遗迹里唯一还活着的，是命令。**

### 1.2 星渊是什么

星渊是遗迹地底的一道**星之裂口**——一颗未熄之星坠落处留下的缺口，向下没有底。星庭在裂口之上造了「晶核」：一枚聚拢星辉、以自身重量压住裂口的楔石。遗迹是围绕这枚楔石长出来的建筑群：

| 房间名（不得改） | 空间语义 | 剧情功能 |
| --- | --- | --- |
| 遗迹前庭 | 外门。第一个"不纳活物"的关卡 | 教玩家：这里的一切都会拒绝你 |
| 星辉回廊 | 导流廊。星辉由此汇向晶核 | 教玩家：越靠近核，拒绝越密 |
| 晶核封印 | 核室。楔石所在，守卫在此 | 与旧令正面相撞 |

三房不是三个关卡，是**一座建筑的由外到内**。这是本作最短、也最省的叙事结构：空间本身就是剧情。

### 1.3 遗迹为何存在

星庭造它，只为"压住"与"看住"：压住裂口，看住楔石。晶核靠星辉维持平衡；星庭亡后无人导引星辉，晶核开始**反向渗出蚀光**。建筑本身没有坏——坏的是它的判据。

### 1.4 侵蚀机制：扭曲判据，而非制造怪物

这是本世界观最关键、也最省成本的一条设定：

> **侵蚀不创造怪物，它改写判据。**

- 蚀光渗入遗迹的"律"（写在造物体内的旧令），把「外廊不纳活物」逐步固化成「凡活物皆敌」。
- 于是遗迹里所有造物仍按原职责行动，只是**把所有活物读成了引侵蚀者**。它们的动作是"驱离"，不是"猎杀"——这正好解释了本作战斗表现：
  - 哨兵：0.55 s 预警 → 劈砍 → 后摇（`default_sentinel.tres`、`sentinel_slash.tres`）。先警告后动手，是看守的动作，不是捕食者的动作。
  - 晶核守卫：横扫 0.8 s 前摇、冲击 1.2 s 前摇（`guardian_sweep.tres`、`guardian_shockwave.tres`）。**极长的前摇就是它的"驱离警告"**；它一直在给来者退路。
  - Boss 每轮外放后必须回吸晶能 → `run_manager.gd:192` 的「恢复中 · 进攻机会」正是它的机械节律，而非设计上的"送破绽"。
- 侵蚀**不新增美术资产、不新增系统**：它只需要几句话，就把"三房都打我"变成设定事实。

### 1.5 时间结构：一夜与黎明（解释短局与重开）

- 结界每晚被侵蚀推挤；**黎明时分星辉自天顶回落，结界重新咬合**，把这一夜的侵蚀压回去（= 胜利文案「结界在黎明时分平息了遗迹的侵蚀」）。
- 但咬合只是"压实"，不是"清除"：若无人进入核室完成一次核定，下一夜只会更盛。
- 因此**一局 = 一夜之末**（5–8 分钟的流程在设定上成立）。
- **失败为什么可以重来**：黎明尚在，结界未合，探索者可以再一次闯入；但试炼区只认一次完整的穿越——**中途退回或身死，门自门首重锁，须从头再过一遍**。这条设定直接对上"失败无检查点、只能整局重开"的现有规则（`run_manager.gd` 只有 FAILED→重开），不需要任何新系统。

### 1.6 为什么孤身（规则化的孤独）

封闭试炼区的入口**只开一次、只容一人**：结界以活物的生气为凭，一人入则门闭；两人同入，星辉共鸣即失衡，蚀光会顺着第二个人的气息反涌。所以孤身不是风格选择，是**规则限定**；这也解释了游戏里没有同伴、没有 NPC、没有援军——不是没做，是**不能有**。

> 顺带补一句设定级的好处：**正因为探索者是外人、不承旧誓，他才是唯一能斩断旧誓的人。** 局内之人无法撤销局内之令，局外之人可以。

## 2. 主要矛盾与主题

### 2.1 一句话主题陈述

> **守夜的是它；斩断这场守夜的，是你。**

拆开说：**晶核守卫是那个从未离开的守望者**——它守着一条已经没人能撤销的旧令，一守就是整座城的死期；探索者只是闯入者，却正因不承此誓，才斩得断它。要守住黎明，须先终结这场守夜本身。

### 2.2 三层矛盾

| 层 | 矛盾 | 玩家如何感知（不靠文本） |
| --- | --- | --- |
| 表层（操作） | 探索者 vs 遗迹造物 | 三房战斗、预警与闪避 |
| 中层（设定） | 闯入者要"过" vs 守夜者不许"近" | Boss 的长前摇、恢复节律、"驱离"式招式 |
| 深层（主题） | 职责 vs 时效：一条正确却过期的命令，由最忠诚的人执行 | 胜利文案只写"稳定"，不写"胜利"；失败文案写"从头"；守卫从不先动手 |

### 2.3 文风约束

- 凝练、克制、古雅；**不解释设定**，只给意象与状态。
- 一律使用陈述句与名词短句；不用感叹号、不用第二人称说教、不用"你一定会……"。
- **禁用**：网络语、现代口语（"搞定/拉满/无敌了/秀操作"）、游戏化旁白（"点击开始你的冒险"）、感叹式营销语。
- 单条弹窗副标题 **≤ 24 个汉字**（含标点算 24 字符内更稳，见 §6 逐条计字）。
- 标点统一：中文全角；分隔用 ` · `（两侧各一空格）与 `，`；**不用破折号**（现有代码全域不用 `——`，保持一致）。

## 3. 角色设定

### 3.1 遗迹探索者（玩家角色）

| 项 | 内容 |
| --- | --- |
| 身份 | **外人 / 闯入者**：循遗迹外溢的蚀光征兆而进入封闭试炼区的人。不承任何旧誓，因此**不被任何一方承认**——守卫视其为夺核者，建筑视其为活物 |
| 装备 | 一柄星刃（技能「星刃斩」即其名），轻甲（对应美术：银发、青围巾、灰蓝分叉外套、浅色肩甲） |
| 动机 | 查明晶核异动、把侵蚀压回去（自保与求知）；不为财宝、不为复仇、事前**不知道**此地有任何旧令 |
| 能力来源 | 他是"**未被旧令登记过的人**"——旧令把所有在册者都判为敌，唯独读不到他，故他能穿过结界、也能与晶核共鸣承接星辉（= 祝福） |
| 限制 | 试炼区入口一开只容一人；进境不可累积（= 每局从零开始） |
| 性格呈现 | 全程无台词。性格只由两处体现：他怎么打，以及看清这里是什么之后**还愿往前走** —— 这是设计选择，不是缺失 |

> 角色写作准则：探索者没有台词，也**不要给他写台词**。他的一切都靠"做了什么"表达：他先看了预警再动，他明知道这里没人要他留下，还是走到了核室。

### 3.2 晶核守卫（Boss，动机自洽三问）

**三问必须先答，否则设定崩：**

1. **它为何阻拦探索者？**
   它的旧令写死为「核室不纳活物，凡近核者皆为夺核者」。星庭曾因一次"取核"之祸而灭城（第一次蚀光外溢），此后守卫的判据被焊死：**不问来意，只问距离**。探索者要近核，所以必战。它不认为自己在行凶，它认为自己在**守住上一次灾难**。
2. **它为何不认探索者（不认这个"同样在往核室走的人"）？**
   它只认名册，而探索者不在名册上；旧令对"未登记者"只有一条处理方式：清除。再加上它的辨识依赖晶体共振，而蚀光已使共振失真——**它读不到人，只读到距离**。它不是在拒绝一个人，是在拒绝一切靠近。这不是它的堕落，是它的忠诚被时间变成了墙。
3. **击败它为何是正确的？**
   因为旧令已经过期且正在杀死遗迹：无人核定 → 结界只能压实不能清除 → 每夜更盛。**斩断旧令，才轮得到新誓生效。** 所以结局只写"晶核已稳定"，不写"击败邪恶"。

**形象与动作对齐（不改美术）**：宽肩晶体、巨锤（`core_guardian.glb`）。招式「重锤横扫」= 近身驱离清扫；「晶能冲击」= 核能外放一圈，把自己推开一段安全距离。两个招式都是**防守动作**，因此前摇才敢长达 0.8 s / 1.2 s —— 它给的从来是警告，不是偷袭。

**名字就是它的职位**：它是这片遗迹里**唯一仍在守望的人**——从城灭那天起，它就站在这里，没换过岗。它不知道自己要守的东西早就没有了。

**悲剧落点**：它是初代守夜人的遗骸与誓约所铸。探索者杀的不是怪物，是**最后一个仍然在岗的守望者**——也就是这场守夜本身。它也正因此才该被斩断：**没有人能替一座死城永远值夜。**

### 3.3 遗迹哨兵（普通敌人）

| 项 | 内容 |
| --- | --- |
| 是什么 | 星庭最低阶的巡守造物，"巡守之律"的末端执行者（不是士兵、不是野兽） |
| 为何敌对 | 同一被扭曲的判据：外廊不纳活物；蚀光使它们的核过热，故行动暴烈 |
| 为何在前庭与回廊 | 前庭为外门（2 具），回廊为导流廊（3 具）——**越近核室，巡守越密**，2→3 不是数值堆叠而是建筑逻辑 |
| 为何与 Boss 同源 | 同一个失效誓约体系：哨兵是末梢，晶核守卫是中枢 |
| 玩家该有的感受 | 拆解，而非屠戮；它们没有恨意，只有流程 |

> 这条设定同时服务难度说明：第 2 房敌人变多，在叙事上是"防线加密"，玩家能接受；不需要额外解释文本。

### 3.4 晶核（非人角色，但有意向）

它没有声音。它在探索者每次清场后**主动分出一点残余星辉**（= 每房结束的祝福三选一）。**它不是随机奖励机，它在求救**：把力量借给唯一读得到它的人。三选一 = 它一次只能回应一种共鸣；同一共鸣一局只能点燃一次（= 现有"同一祝福每局最多获得一次"规则）。这是把**既有玩法规则翻译成设定**，不改任何数值。

### 3.5 星庭（已亡文明，背景角色）

不出场、不出现名词、不进入 UI。它只以两件事存在：建筑（遗迹）与命令（旧令）。**写作纪律：任何文案都不得提到"星庭"，让遗迹自己说话。**
